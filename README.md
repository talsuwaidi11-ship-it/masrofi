# مصروفي

تطبيق ويب عربي لتسجيل المصاريف الشخصية ومصاريف المشاريع (مثل بناء البيت) على الايفون.

- كل البيانات تنحفظ في متصفح Safari على جهازك فقط. ما في سيرفر ولا حساب.
- أقسام ومشاريع بلا حد، ميزانيات، عقد المقاول، دفعات مستحقة، صور الفواتير، قفل برمز.
- تقارير PDF وExcel، وملف نسخة احتياطية.

## التشغيل على الايفون

افتح https://talsuwaidi11-ship-it.github.io/masrofi/ في Safari، ثم زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

ملف واحد فقط (`index.html`) بدون أي خطوات بناء.
